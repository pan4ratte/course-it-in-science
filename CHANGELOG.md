# Changelog

## 1.3.0

### Добавлены новые lua-фильтры для Pandoc, уже существующие исправлены

Новые фильтры:

* `table-styles.lua` исправляет проблему, из-за которой Pandoc у всего текста в таблице сбрасывает стили с назначенных на `Compact`. О том, как использовать, см. в руководстве.
* `table-verbatim.lua` позволяет вставлять в таблицу `код`, используя для этого не стандартный стиль, а собственный. Полезно, когда оформление текста в таблице отличается от стандартного.

Исправления фильтров:

* `figures.lua` теперь работает как и задумывалось. Картинки *без* подписи теперь обрабатываюся корректно.
* `today-date.lua` и `today-date-ru.lua` теперь работают как и задумывалось. `$today` теперь можно вставить в *любое* место документа.


## 1.2.0

### Добавлены новые lua-фильтры для Pandoc

Новые фильтры разработаны с нуля и решают давно известные проблемы в Pandoc, которые до сих пор не исправлены разработчиками.

* Решение проблемы корректного назначения стиля для встроенных в документ изображений (`figures.lua`).
* Решение проблемы корректного назначения стилей для нумерованных и маркированных списков (`list-styles.lua`/`list-styles-old.lua`).
* Также, добавлены фильтры для автоматической вставки сегодняшней даты в любое место документа при экспорте (`today-date.lua`/`today-date-ru.lua`). 

Подробнее см. на главной странице репозитория. 

## 1.1.0

### Обновление стилей цитирования

* Стили цитирования сихронизированы с [библиотекой](https://github.com/pan4ratte/zotero-gost-styles). Добавлено пять новых стилей:
    
    * Два дополнения к существующему с правилами сортировки библиографии по хронологии и по порядку упоминания в тексте.

Подробнее см.: https://github.com/pan4ratte/zotero-gost-styles/releases/tag/3.0.0 


## 1.0.0

### Начальный релиз

* **Папка Pandoc в папке Obsidian.** Представляет собой папку пользовательских данных с минимальным набором файлов для автоматизации написания научных работ в Obsidian:

    * Папка `filters` содержит lua-фильтры: `pagebreak.lua` для обработки ручных разрывов страниц при экспорте, а также `zotero.lua` для конвертации pandoc-цитирований в live-цитирования Zotero при экспорте.
    * Файл стиля цитирования `gost2018.csl` предназначен для отображения цитирований в тексте внутри Obsidian (не влияет на экспорт).
    * Файлы `reference-gost-12.docx` и `reference-gost-14.docx` представляют собой шаблоны, которые pandoc использует для оформления документов при экспорте. Оформлены с базовым соблюдением требований для оформления работ по ГОСТ.

* **Папка Zotero.** На данный момент содержит только актуальную версию разработанного мной стиля цитирования по ГОСТ 2008 с поправкой на постраничное цитирование.
